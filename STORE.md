# Zepp Store Listing Draft

## Name

WristTrack

## Short description

Start and stop your Toggl Track timer from an Amazfit Bip Max.

## Full description

WristTrack puts the essential Toggl Track timer controls on your wrist. View
the running entry, elapsed time, and project; stop it with one tap; or start a
new timer from your configured default and recent entries.

The integration is serverless. Your paired phone communicates directly with
Toggl Track over HTTPS, and your personal token is never sent to the watch or
to a developer-operated server. A paired phone with internet access is
required.

WristTrack is an independent client and is not affiliated with or endorsed by
Toggl OÜ or Zepp Health.

## Category

Productivity

## Permissions

- Device information: used to render the interface for the supported watch.

## Review notes

The app requires the tester to paste a Toggl Track API token in the Zepp app's
WristTrack settings. Toggl currently provides personal-token authentication,
not OAuth, PKCE, or device authorization, for third-party API clients.
